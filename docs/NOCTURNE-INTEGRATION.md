# Nocturne Integration

The Voice Beneath the Pines uses the reusable interaction language established by The Nocturne Machine without copying Nocturne's visual identity.

## Canonical distinction

> Nocturne is a machine that responds to you.
>
> The Voice Beneath the Pines is a story that notices you.

## Systems translated into the story

- deterministic atmospheric particles
- cursor-responsive movement
- layered aura/bloom
- breathing light
- living/parallax imagery
- orbital geometry
- state-based atmosphere
- progressive reveal states
- supernatural environmental response
- reduced-motion support

## Interaction arc

Campfire → story → Diedre → mother's voice → road → mirror reveal → return to fire.

The viewer's presence is part of the atmosphere rather than a decorative cursor effect.
